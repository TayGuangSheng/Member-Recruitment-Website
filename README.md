# NE CE Member Recruitment

A playful interactive web page to recruit new members into the Northeast Community Engagement Department.

## Overview

This is a lightweight, single-page HTML/CSS/JavaScript project that invites visitors to join the Northeast Community Engagement (CE) Department. It uses fun, animated interactions:

- A “Yes / No” prompt where the “No” button playfully dodges the cursor.
- Clicking “Yes” reveals a welcome message and instructions to share a screenshot.
- Built to be easily dropped into any static-site hosting environment.
